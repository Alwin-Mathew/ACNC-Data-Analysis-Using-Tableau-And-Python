# ACNC-Data-Analysis-Using-Tableau-And-Python
This contains Python code and Tableau workbook having ACNC data analysis

**Objective : **
A team of 20 analysts who would like to give 2 hours each per week to support a philanthropic cause.

Among 50k+ charities registered under Australian Charities and Not-for-profits Commission (ACNC) where to invest their time to generate the maximum value for society.

Using any data available from an official Government or an official organization digital source with a URL formatted as www.{...}.org or www.{…}.gov.au, do a research and come up with an analysis

**Problem Statement :**

Which charities the team should contact to offer their support and why?
